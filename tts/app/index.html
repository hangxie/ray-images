Generate speech

Speed re-times the finished audio while preserving pitch. Volume is the output loudness in LUFS every voice is normalized to, so each one plays at the same level; a louder target is capped to avoid clipping. Neither changes how the voice is generated.

Generation settings

Lower temperature or top-p makes delivery steadier and split paragraphs more alike, but flatter; very low values can cause repetition. Top-k 0 disables it. Max tokens caps each request at 12.5 tokens per second of audio; left empty, it is set from the text length at about twice normal speech. Set it for text that runs long when spoken, such as acronyms.

    With splitting on, each paragraph (line) is generated as its own request, one at a time, and plays in order as it returns. Check voice similarity, naturalness, missing or repeated words, glitches, seams between paragraphs, and the ending. Reference clips use their matching transcript. Audio is generated on the homelab GPU; live results stay in the browser.
